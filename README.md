# 民逸跆訓 林聖翔・林聖宸 跆拳道比賽紀錄

**網站：https://ruru02044567.github.io/lin-brothers-taekwondo/**

高雄市福山國小、民逸跆訓兩位跆拳道選手林聖翔與林聖宸的完整比賽獲獎紀錄。
資料整理自 36 張獎狀正本，逐張核對。

## 選手

### 林聖翔（哥哥）

高雄市福山國小、民逸跆訓。目前黑帶，37 公斤級。

民國 112 年至 115 年共 20 場獲獎紀錄：第一名 8 次、第二名 8 次、第三名 4 次。
其中 14 場為全國級賽事。

代表成績：民國 115 年第三屆全國理事長盃跆拳道錦標賽，國小 4-6 年級男子黑帶組 37 公斤級第一名。

完整紀錄：https://ruru02044567.github.io/lin-brothers-taekwondo/lin-sheng-xiang.html

### 林聖宸（弟弟）

高雄市福山國小、民逸跆訓。目前色帶，34 公斤級。

民國 113 年至 115 年共 16 場獲獎紀錄：第一名 7 次、第二名 5 次、第三名 2 次、第四名 2 次。
其中 11 場為全國級賽事。

代表成績：民國 115 年第三屆全國理事長盃跆拳道錦標賽，國小 4-6 年級男子色帶組 34 公斤級第一名。

完整紀錄：https://ruru02044567.github.io/lin-brothers-taekwondo/lin-sheng-chen.html

## 比賽足跡

兩兄弟四年間在七個縣市出賽，共 36 場獲獎：

| 縣市 | 場次 |
|---|---|
| 高雄市 | 20 |
| 屏東縣 | 4 |
| 全國協會主辦 | 4 |
| 臺中市 | 2 |
| 新竹縣 | 2 |
| 苗栗縣 | 2 |
| 嘉義市 | 1 |
| 新北市 | 1 |

主要參賽的賽事包括高雄市市長盃、高雄市議長盃、高雄市理事長盃、高雄市主委盃、
屏東縣主委盃、苗栗縣體育會理事長盃、竹東鎮長盃、新北議長盃、嘉義市理事長盃、
中華師聖盃、中華盃全國武術功夫錦標賽跆拳道經典賽、全國理事長盃跆拳道錦標賽。

## 網站功能

- 三頁：總覽、林聖翔、林聖宸
- 可搜尋賽事名稱、縣市、組別、年份
- 可依賽事層級與名次篩選
- 點任一列查看該張獎狀原圖
- 兩張圖表：逐年獎牌數配腰帶進程、各縣市出賽場次

## 技術說明

純靜態網站，無框架。資料源為 `獎狀資料.json`，
由 `工具/` 底下的四支 Python 腳本產生 `docs/` 內容。

重建指令：

```
python -X utf8 工具/build_css.py
python -X utf8 工具/build_charts.py
python -X utf8 工具/build_site.py
python -X utf8 工具/build_seo.py
```
